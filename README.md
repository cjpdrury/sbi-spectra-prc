# Paper Reproducibility Challange 
This repo was developed as part of a challenge on the Mancheter AI CDT Paper Reproducibility Challange. The idea is to develop your own code to reproduce the results of a paper, as an exercise in scientific practice, coding documentation, and to further technical skills. 

The paper selected for reproducibility is: 

"Simulation-based inference with neural posterior estimation applied to X-ray spectral fitting: Demonstration of working principles down to the Poisson regime". 
Authors: Didier Barret and Simon Dupourqué. 
DOI: 10.1051/0004-6361/202449214. 

The original paper repo can be found at: https://github.com/dbxifu/SIXSA. 
Much of the code seen in this repo was originally written by the paper authors. All results and findings are attributed for them.
